# DevutiliX

A comprehensive, privacy-first developer utility suite built with **Next.js (App Router)**, **React 19**, and **Tailwind CSS v4**.

## ✨ Features

- **71 Essential Developer Tools:** Spanning Data, Security, Encoding, Images, Web, Time, Color, CSS, Math, Text Processing, DevOps, and Generators.
- **Privacy-First:** 100% client-side computation. No tokens, passwords, or data are ever transmitted to external servers.
- **Next.js App Router Architecture:** Pre-rendered static pages (`generateStaticParams`) for all 71 utilities with full SEO and Open Graph metadata support.
- **Google Font Optimization:** Zero-CLS with `next/font/google` (Manrope).
- **Fast Fuzzy Search:** Powered by Fuse.js.
- **Dark Mode Support:** Smooth light/dark theme switching with persistent local storage.

## 🛠️ Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production

```bash
npm run build
```

### 4. Start Production Server

```bash
npm run start
```
